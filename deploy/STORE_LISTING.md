## Description

מסלול חובש עוזר לך לעבור את קורס חובשי רפואת החירום: לימוד מסודר לפי נושאי הקורס, תרגול שאלות ומבחן מסכם.

• 49 נושאים בחמישה פרקים: אנטומיה, החייאה ודפיברילטור, מצבי חירום רפואיים, טראומה, פגיעות סביבה, הריון ולידה, אר״ן וחומ״ס ועוד.
• 789 שאלות אמריקאיות עם הסבר לכל תשובה.
• 272 תמונות להמחשה: אנטומיה, חוסם עורקים, סד, עירוי, אפיפן, נחשים ועקרבים בישראל ועוד.
• כרטיסיות לשינון וטבלת "מספרים לשינון" (מבוגר, ילד ותינוק).
• מבחן מסכם עם ציון עובר, ומסך תוצאות לפי נושאים.
• תרגול הטעויות שלך.
• מטרונום החייאה עם ספירה, הנשמות והתראה כל 2 דקות.
• עובד גם בלי אינטרנט. אפשר להתחבר לחשבון כדי לסנכרן את ההתקדמות בין מכשירים.
• מצב כהה, גודל טקסט מותאם וממשק בעברית מלאה.

החומר נועד לחזרה ולתרגול, ואינו מחליף את מצגות הקורס, את ההדרכה או את הפרוטוקולים הרשמיים.

## App Privacy / Data safety answers
- Every install gets an automatic anonymous account (random ID) holding app activity (quiz answers/progress). Email address and name (optional) only if the user adds them. Linked to the user, used for App Functionality only. Not used for tracking, not shared, not sold.
- Encrypted in transit: yes (HTTPS). Users can delete their account and data in the app (Settings → Account → Delete account).
- No location, contacts, photos, identifiers, ads or analytics SDKs.

## Review notes (App Store)
An anonymous account is created automatically on first launch; no sign-in is needed. To use the account on another device, add an email and password in Settings → Account. Account deletion: Settings → Account → מחיקת חשבון.
